# Support

Need help using or running **TuPay**? This page points you to the right
channel for each kind of question.

## Documentation

Start here — most questions are answered in the project docs:

- [`README.md`](README.md) — overview, features, quick start.
- [`ARCHITECTURE.md`](ARCHITECTURE.md) — system design, data flow, security,
  deploy.
- [`CODE_STYLE.md`](CODE_STYLE.md) — conventions, patterns, CI gates.
- [`docs/MODULE_MAP.md`](docs/MODULE_MAP.md) — domain ownership and request
  paths.
- [`docs/API_DOCS.md`](docs/API_DOCS.md) — API envelope, errors, money/date
  formats.

Live API reference is served by the app at
<http://127.0.0.1:5000/swagger/index.html>.

## Asking questions

Use [GitHub Discussions](../../discussions) for "how do I…" questions, ideas,
and general help. **Do not** open a Discussion for:

- **Bug reports** — open an issue using the
  [bug report template](.github/ISSUE_TEMPLATE/bug_report.md).
- **Feature requests** — open an issue using the
  [feature request template](.github/ISSUE_TEMPLATE/feature_request.md).
- **Security vulnerabilities** — follow [`SECURITY.md`](SECURITY.md); do not
  post publicly.

## Issue templates

- **Bug report** — `.github/ISSUE_TEMPLATE/bug_report.md`
- **Feature request** — `.github/ISSUE_TEMPLATE/feature_request.md`

Please fill in the template completely. Incomplete reports are harder to
triage and may be closed.

## Response time

TuPay is an open-source project maintained on a best-effort basis. There is
**no guaranteed response time** and **no SLA**. Be patient, be polite, and be
ready to dig in — see [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md).

## Contributing

Want to fix the issue yourself? Read
[`CONTRIBUTING.md`](CONTRIBUTING.md) for the local setup, branching model,
and PR process. Pull requests targeting `dev` are welcome.

## Commercial / production support

TuPay does not provide commercial support. For production deployments,
review [`ARCHITECTURE.md`](ARCHITECTURE.md) (deploy section) and
[`SECURITY.md`](SECURITY.md) (best practices) first.
